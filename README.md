# Jueguito del Topo

Un pequeño juego inspirado en "Whack-a-Mole" desarrollado para practicar GitHub, HTML, CSS y JavaScript.

## 🚀 Tecnologías

- HTML
- CSS
- JavaScript

## 📦 Instalación

Clona el repositorio:

```bash
git clone https://github.com/youh13r-dotcom/jueguito-del-topo.git
```

Entra al proyecto:

```bash
cd jueguito-del-topo
```

Abre el archivo `index.html`
